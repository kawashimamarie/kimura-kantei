## C2案との違い
C2案は「あたたかいアイボリー＋深緑、ファーストビューで相談内容を選ぶタイル、代表の顔写真、丸いボタン」。参考サイトは「白＋紺＋金、大きな明朝の見出し、全幅写真、罫線とタグ付きの一覧、角ばった要素」。

## R-A でやったこと／やらなかったこと
- 取り入れた：配色（紺・金・薄灰）、大きな明朝見出し、全幅の写真帯、傾けた紺の面付き写真、角に二色の三角のカード、紺タグの一覧行、写真タイル、紺のお問い合わせ帯、灰色フッター
- 使わなかった：参考サイトの文章・写真・ロゴ・図形（ヒーローの円は「SINCE 2006」の独自の図）
- 木村不動産鑑定の会社情報・サービス内容・資格・連絡先は既存データ（`src/data/`・`src/content/`）をそのまま使用

## 修正（2回目）
- ロゴ：既存の正式ロゴ画像（`public/assets/img/logo/kimura-logo.png`）をそのまま使用（ヘッダー・フッター。画像の比率・配色は変更なし）。仮ロゴ・独自の円マークは撤去し、ヒーロー右は文字だけの「Since 2006」に変更
- 「ご相談内容」カード：アイコン・イラストをやめ、番号（01〜06）・サービス名・短い説明・罫線・矢印だけで構成。AI生成画像への置き換えもなし

## 仕上げ（3回目）
- ヘッダー：正式ロゴ画像＋社名・事務所名。高さ スマホ68px／PC 88px、ロゴ幅 54〜70px
- ファーストビュー：キャッチコピー「不動産の価値を、根拠とともに。」は変更せず、余白・行間・写真との間隔を調整
- ご相談内容カード：番号・名称・説明・罫線のみ。左上の二色三角は「なし」を標準、「あり」は URL に `?cards=tri` を付けると表示（比較用）
- 会社案内への誘導：全幅の写真つきバナー1つに整理（写真の取り違えを避けるため、代表紹介の別タイルはやめた）
- 事例：PC は既存の事例写真のサムネイル付き
- 余白：セクション上下をスマホ80px／PC 128px に統一。見出し（英字＋日本語）の大きさを揃えた
- スマホ：タップ領域44px以上、固定ボタンと本文の重なりなし（下余白＋safe-area）、JS無効でもメニュー表示

## 単独の確認用プレビューの書き出し（別リポジトリ向け）
`cd site && npm run build:ra-preview -- <出力先フォルダ> [ベースパス]`（既定のベースパス `/kimura-kantei-ra-preview`）
- R-A案トップだけを書き出す。比較用バー・開発ツールは含まない。未制作の下層ページへのリンクは「確認用プレビューです」の案内（ダイアログ／JS無効時はページ内の案内）になる。仮のページは作らない
- noindex・robots.txt（Disallow: /）・プレビューバナーあり。フォームはない
- C2案の公開物（リポジトリ直下・`build:pages`）には影響しない

## 最終ブラッシュアップ（4回目）
- ご相談内容カード：上の濃い線・個別の外枠をやめ、1枚の白い面を細い罫線で6つに区切る形に。番号・名称・説明・矢印は維持（三角・アイコンは復活させない）
- メニュー：開閉とも opacity と transform の CSS transition（開 300〜420ms／閉 約300ms、ease-out 系）。×への変形、背景の暗幕、背面スクロール停止、Esc・暗幕タップで閉じる、キーボード操作時のみ先頭リンクへフォーカス、Tab はメニュー内を循環、reduced-motion では即時
- スクロールアニメーション：`html.ra-anim`（JS が動いたときだけ）の下で、画面の下にある要素だけを opacity＋transform（16px・800ms・時間差90ms）で表示。JS無効・失敗・reduced-motion では何も隠さない
- ホバー：`(hover: hover) and (pointer: fine)` の端末だけ。役割ごとに、ナビは文字色＋下線、カードは背景＋番号色＋矢印、一覧は下線が伸びる＋写真が少し拡大＋矢印、ボタンは2px浮く＋影、会社案内は写真が少し拡大、フッターは下線
